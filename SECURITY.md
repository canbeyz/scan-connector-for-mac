# Security and privacy

Use this experimental app only with a printer on a trusted local network. It has not had an independent security audit. Do not expose the app or printer directly to the Internet.

The app needs local network access to discover and communicate with the selected printer. Some local communication and scan data may be unencrypted. A certificate change requires verifying the selected device before reconnecting.

No analytics or cloud upload is included. Settings contain local device identifiers, a certificate fingerprint, and a folder path. PDFs contain user data. Redact these before any public issue report.

For vulnerabilities, use GitHub's private [Report a vulnerability](https://github.com/canbeyz/scan-connector-for-mac/security/advisories/new) option. Never include scans, settings, credentials, or diagnostic captures in public issues.

There is no guaranteed response time.
