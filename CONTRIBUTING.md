# Contributing

Build on Apple silicon with Xcode Command Line Tools and run the native checks and printer-free fixture tests in README.md. State the printer model, firmware, macOS version, paper source, and verification limits when reporting hardware tests.

Use synthetic fixtures and documentation addresses. Do not add personal scans, settings, device identifiers, certificate pins, credentials, or diagnostic captures. Identify the source and license of added code and assets, and preserve required notices.

Keep the UI in plain English, retain the 15-character destination-name limit, and migrate existing preferences when adding settings. Distributable forks should use their own bundle identifier and signing identity.

Contributions are intended for distribution under MIT. Preserve copyright and third-party notices.
